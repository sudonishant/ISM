## 🚀 Setting Sail (Installation & Quick Start)

### 1. Clone the Fleet:
```bash
git clone https://github.com/sudonishant/ISM.git
cd ISM/seven-seas-college
```

### 2. Launch Local Port:
```bash
# Using Python 3 built-in server:
python3 -m http.server 8080 --bind 0.0.0.0
```
Open your browser and sail to: **`http://localhost:8080`**

### 3. Recompiling the 16 Pages:
Whenever you modify `build.js`:
```bash
node build.js
```
*Compiles all 16 pages in < 150ms with zero npm bloat!*
